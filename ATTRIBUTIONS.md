# Upstream Attributions & Lineage

OmniREA is built upon and consolidates groundbreaking research, tools, and methodologies from four core open-source projects:

### 1. REA (Reverse Engineering Anything)
- **Author**: [morluto](https://github.com/morluto/rea)
- **License**: MIT License
- **Contribution**: The 207+ tool Model Context Protocol (MCP) server architecture, native decompiler bridges, memory inspect APIs, and unified evidence bundle system.

### 2. ReAgent
- **Author**: [Dryxio](https://github.com/Dryxio/reagent)
- **License**: MIT / Apache 2.0 License
- **Contribution**: The 11-signal dynamic parity framework, register and memory state recording, and Unicorn CPU differential emulation engine.

### 3. REAP (REA Investigation Prompts)
- **Author**: [Joas A. Santos](https://github.com/JoasASantos/REA-Prompts)
- **License**: MIT License
- **Contribution**: The 16 domain-specific reverse engineering prompt playbooks and tri-bucket output standards (`PROVEN / HIGH-CONFIDENCE / HYPOTHESIS`).

### 4. LeanREA
- **Author**: [aicodeking](https://github.com/aicodeking/leanrea)
- **License**: MIT License
- **Contribution**: Zero-MCP fast-path CLI reconnaissance patterns, token elimination benchmarks, and two-tier triage philosophy.
